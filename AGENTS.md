# Glance

- Product: local-first weekly schedule editor and Liquid Glass wallpaper compositor.
- The app is in this repository root: React, TypeScript, Vite, static `dist/` output. Keep the app deployable to Cloudflare Pages without a server or database.
- Current scope includes the schedule grid, plain PNG export and photo-based Liquid Glass wallpaper design/export. Do not add authentication or calendar integrations unless requested.
- Schedule defaults: Monday–Friday, 09:00–21:00. Users choose any weekdays and a shared daily display range within 00:00–24:00, with 15-minute precision. Keep weekday and minute-based event data separate from rendering; preserve events outside the display range.
- Categories are user-owned: editable names/colors and add/remove with reassignment for used categories. Seed colors: purple learning; blue work; orange meetings; gray personal plans; green leisure. Keep existing category IDs compatible with saved projects. Weekly allocation totals derive from events, including those outside the display range.
- Visual preference: event titles and times use a darker shade of their category color on opaque pastel fills. Grid lines are hourly with subtle half-hour subdivisions, hidden behind event cards; editing still snaps to 15 minutes. Preserve this when extending the editor.
- Undo uses ⌘Z / Ctrl+Z only, with a subtle shortcut hint and no toolbar button. Preserve native text undo inside editable fields; do not undo committed project changes during a dialog or active drag.
- Keep event resizing distinct from moving: a visible bottom-center grip on hover/selection, enlarged pointer target, and vertical-resize cursor throughout resizing. Keep the card body available for moving, including short events.
- Public starter data must use fictional, generic events and times, never user-provided schedules. Preserve existing locally saved projects when updating defaults.
- Persist committed project settings in validated, versioned localStorage. Store the original photo Blob separately in browser IndexedDB; never put it in localStorage or upload it.
- JSON v4 includes events, grid layout, categories, grid days/start/end and wallpaper position/size/opacity/blur/tint/radius. Preserve v1–v3 migration and project undo. Photo replacement/removal is separate from project history. Keep all file processing local; do not add analytics or schedule uploads without an explicit request. Treat event names and exported plaintext JSON as potentially private.
- PNG export renders the entire configured grid locally on canvas, independent of viewport scrolling. Use committed data, category-colored text and opaque pastel cards on white. Preserve display clipping, layout settings and 2× output where practical; cap dimensions/pixels for large grids. No selection decorations or editing controls in exports.
- Local reference screenshots live outside this repository and include iOS chrome. Wallpaper export needs a clean original photograph. Preserve original image pixels; never use image generation for the final wallpaper. Match the dark glass panel, category-tinted text and reserved clock area. Preview and export must share the canvas compositor, including blur/highlights/refraction; guides never enter the PNG.
- Read `docs/product.md` and `docs/architecture.md` for durable product context. Run `npm test` and `npm run build` from the repository root after logic changes.
- Public hosting: GitHub Pages from `.github/workflows/deploy.yml` on pushes to `main`. The workflow supplies Vite’s base path; use `import.meta.env.BASE_URL` for root links. Preserve `/` as the default build target for other hosts. The `.openai/hosting.json` describes a separate private preview.
